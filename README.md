## Panduan Screenshot Tugas

Simpan semua file tangkapan layar (screenshot) di dalam folder `screenshots/` dengan format nama angka (`1.png` sampai `8.png`) sesuai tabel berikut:

| No File | Aplikasi / Lokasi | Yang Di-screenshot |
| :--- | :--- | :--- |
| `1.png` | VS Code (Editor) | Kode struktur HTML5 pada `index.html` (`<!DOCTYPE html>`, `<html>`, `<body>`). |
| `2.png` | Browser | Tampilan `<h1>`, `<p>`, dan teks paragraf di browser. |
| `3.png` | Browser | Tampilan pemformatan teks (`<b>`, `<i>`, `<sub>`, `<sup>`, `<del>`). |
